# Kentucky Cannabis: Workshop images

Images shown in the Steam Workshop description of
[Kentucky Cannabis](https://steamcommunity.com/sharedfiles/filedetails/?id=3806443105),
a Project Zomboid (Build 42) mod.

They are drawn like the mod's in-game windows, from the mod's own sprites and icons and the
game's UI art. Every number is a default setting; all of them can be changed in sandbox options.
